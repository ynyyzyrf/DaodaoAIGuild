# DaoStore 前端 UI 調整需求文檔

## 背景

參考圖展示了一套更偏交易撮合型的 DaoStore 前台：首頁聚焦「企業需求 -> 咨詢公司承接 -> FDE 交付」，找咨詢公司頁聚合供給方卡片與篩選，企業/FDE 工作台用指標卡和待辦列表承接後續操作。現有代碼已具備需求提交、機會池、咨詢公司中心、個人中心、排行榜與用戶 Profile API，因此本次優先做前端信息架構和視覺層調整，不新增後端流程。

## 不做範圍

- 不刪除 `/agents` 與 Hermes Agent 管理能力；新增 `/fde` 承載「找咨詢公司」市場頁。
- 不新增未驗證的社交/支付/私信後端功能；可見 CTA 只跳轉到現有路由。
- 不改變「咨詢公司直接接單成功」的既有業務流。

## 路由映射

- `/`：參考圖左上首頁，承擔需求搜索、熱門方案、FDE 榜單、信任入口。
- `/fde`：參考圖右上「找咨詢公司」，使用現有排行榜/用戶 Profile 入口構造可篩選供給方市場。
- `/company-center`：保留企業/咨詢公司工作台能力，後續可向參考圖左下的側欄 + 指標卡收斂。
- `/me`：保留多身份個人中心，後續可向參考圖中下/右下的 FDE 工作台與 Profile 合併形態收斂。
- `/agents`：保留為 Hermes Agent 管理頁，不在主導航露出。

## 首頁需求

1. 首屏採用全寬沉浸式背景圖，保留 DaoStore 暖紅品牌色與白卡質感。
2. 首屏文案聚焦「企業有難題，FDE 有解法」，提供可輸入的搜索框與「立即找咨詢公司」主 CTA。
3. 左側展示平台信任數字：企業需求、FDE/咨詢公司、交付滿意度。
4. 首屏下方展示能力 Chips：經銷商評估、銷售增長、流程自動化、企業知識庫。
5. 熱門方案區展示三張服務卡，包含圖片、標題、成交/下單數、價格與下單 CTA。
6. 右側展示 FDE 排行榜，復用現有 `/users/leaderboard` API；失敗時要有安靜降級。
7. 首頁底部保留「真實項目、專業人才、安全交易、高效交付」的信任入口。

## 找咨詢公司頁需求

1. 新增 `/fde` 頁，頁頭包含標題、說明、搜索框、篩選 Chips 與排序入口。
2. 左側為專業領域分類：全部、AI Agent、數據分析、營銷增長、內容創作、流程自動化、企業知識庫、產品設計、更多。
3. 右側為 3 列人才卡片，使用現有排行榜資料；缺少真實履歷字段時用可解釋的本地展示文案補齊。
4. 卡片展示頭像、姓名、方向、年限、評分、標籤、可接單狀態與「查看詳情」鏈接。
5. 搜索/分類/排序在前端本地可互動；不新增後端查詢參數。

## 導航需求

1. 主導航從純 CTA 型 Header 調整為參考圖的信息架構：首頁、找咨詢公司、需求廣場、問題廣場、龍蝦學院。
2. 「找咨詢公司」鏈接到 `/fde`，不再把 Hermes Agent 管理作為主入口。
3. 已登入用戶保留一鍵導航、提交需求、申請入駐、個人菜單能力。
4. 內容頁不再展示左側頁內導航欄，問題廣場、龍蝦學院與社區頁主內容居中呈現。

## 視覺準則

- 沿用 `brand` 暖紅、slate 中性色、白卡、柔和陰影與 8-16px 圓角。
- 避免純裝飾漸變頁；主視覺使用現有 `web/public/banners` 圖片資產。
- 卡片信息密度提高，但手機端需單列堆疊且按鈕文字不溢出。

## 驗收

- `npx tsc --noEmit --pretty false` 通過。
- 首頁與 `/fde` 可在本地 Next.js 渲染，桌面寬度下接近參考圖的信息層級。
- 不引入未追蹤大文件，不改動後端 API。
