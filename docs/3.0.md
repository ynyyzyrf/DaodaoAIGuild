# DaoDao FDE 社區 3.0 需求文檔
## 生態入口簡化版

**版本：** V3.0  
**產品：** DaoDao FDE Community / 龍蝦騎士社區  
**版本重點：** 在現有社區能力上，增加簡單的生態跳轉入口，不做複雜整合。

---

# 1. 版本目標

V3.0 不做大規模能力整合，核心目標只有三個：

1. 增加「一鍵導航」
2. 增加「知識庫」跳轉入口
3. 為後續 DaoClaw Community / Skill / MCP 能力預留入口

本期原則：

> **先把入口做出來，先讓用戶可以跳轉，不做複雜整合。**

---

# 2. 一鍵導航

## 2.1 功能定位

在 FDE 社區中增加一個統一的快速導航入口，方便用戶跳轉到 DaoDao 生態內其他系統。（鏈接我後補給你）

目前支持：

- DaoStore
- DaoClaw
- SkillHub
- Dify
- GitLab

---

## 2.2 交互方式

在社區頂部導航欄或固定位置增加：

> **一鍵導航**

點擊後，可以展示一個簡單的下拉菜單 / Popup。

例如：

```text
一鍵導航

DaoStore      →
DaoClaw       →
SkillHub      →
Dify          →
GitLab        →
```

點擊對應產品後：

> **直接打開對應系統 URL。**

---

## 2.3 本期只做

- 固定入口
- 顯示產品名稱
- 顯示產品 Logo / Icon（如有）
- 點擊跳轉

---

## 2.4 本期不做

- SSO
- 賬號同步
- 權限同步
- 最近使用
- 收藏
- 使用頻率排序
- 系統狀態
- API 深度整合

以上能力後續有需求再增加。

---

# 3. 知識庫

## 3.1 功能定位

知識庫本期不在 FDE 社區內重新做一套 Wiki / 文檔系統。

直接使用現有的：

> **飛書文檔**

FDE 社區只提供一個跳轉入口。

---

## 3.2 UI 參考

參考 TraeWork 社區的做法：

在網站頂部導航欄直接增加：

> **知識庫**

與其他導航按鈕保持同級。

例如：

```text
首頁    社區    龍蝦學院    知識庫    一鍵導航
```

點擊「知識庫」後：

> **直接跳轉到指定的飛書文檔 / 飛書知識庫地址。**

不需要先進入社區內的知識庫列表頁。

---

## 3.3 本期只做

- 頂部「知識庫」按鈕
- 點擊後跳轉飛書文檔
- 可配置跳轉 URL
- 新窗口 / 當前窗口打開方式可配置

---

## 3.4 本期不做

- 文檔分類頁
- 知識庫首頁
- 文檔卡片
- 文檔搜索
- 飛書內容同步
- 文檔摘要
- 權限同步
- 社區文章自動收錄
- 全文檢索

本期本質上就是：

```text
FDE 社區
   ↓
點擊「知識庫」
   ↓
飛書文檔
```

---

# 4. 龍蝦社區 / DaoClaw Community

V3.0 可增加一個「龍蝦社區」或「DaoClaw Community」入口。

現階段主要作為能力入口與後續擴展預留。

支持方向：

- Skill
- MCP

本期可以先做到：

- 顯示入口
- 點擊進入對應頁面 / 社區
- 為 Skill、MCP 後續能力預留位置

如果目前 Skill / MCP 功能仍未完整確認，本期不需要做深度接入。

---

# 5. 頂部導航建議

V3.0 頂部導航可以保持非常簡單：

```text
Logo

首頁
問題廣場
龍蝦學院
龍蝦社區
知識庫

                     [一鍵導航]
                     [發布]
                     [個人頭像]
```

其中：

### 知識庫
直接跳飛書。

### 一鍵導航
點擊展開：

```text
DaoStore
DaoClaw
SkillHub
Dify
GitLab
```

全部都是 URL 跳轉。

---

# 6. 一鍵導航 UI 建議

不需要做成大型生態門戶。

推薦使用一個乾淨的小型 Popup：

```text
┌─────────────────────┐
│  一鍵導航            │
│                     │
│  ◉ DaoStore      →  │
│  ◉ DaoClaw       →  │
│  ◉ SkillHub      →  │
│  ◉ Dify          →  │
│  ◉ GitLab        →  │
└─────────────────────┘
```

風格保持：

- 白色背景
- 淺灰 Border
- 輕微陰影
- DaoClaw 紅色 Hover / Active
- 不做複雜卡片
- 不做二級頁

---

# 7. 知識庫 UI 建議

參考 TraeWork 社區：

直接在 Header 顯示：

> **知識庫**

不增加多餘圖標和說明。

Hover：

- 字體變紅 / 淡紅背景

點擊：

- 直接打開飛書文檔

核心原則：

> **知識庫是一個入口，不是一個新產品。**

# 9. 驗收標準

## 一鍵導航

用戶點擊「一鍵導航」後：

- 可以看到 DaoStore / DaoClaw / SkillHub / Dify / GitLab
- 點擊任意產品，可以正確跳轉
- 不需要額外登入流程整合

## 知識庫

用戶點擊 Header 中的「知識庫」：

- 可以直接打開指定飛書文檔
- 不經過中間列表頁
- 不需要社區內再次搜索或分類

---

# 10. V3.0 核心原則

V3.0 不追求把 DaoDao 生態一次全部打通。

本期只做：

> **「把入口放在一起」。**

因此整個版本應保持：

**簡單、快速、低成本、可擴展。**

最終用戶感受應該是：

> 在 FDE 社區裡，我可以很方便地找到知識，也可以一鍵前往 DaoStore、DaoClaw、SkillHub、Dify 和 GitLab。
